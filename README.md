# Stock Market Data Dashboard

This project is a Stock Market Data Analysis Dashboard created using Power BI, Tableau, and Excel.

## Project Overview
The dashboard helps analyze stock market data and understand trends, prices, performance, and key insights.

## Tools Used
- Microsoft Excel
- Power BI
- Tableau
- GitHub

## Files Included
- Stock_Data.xlsx – Raw stock market dataset
- Stock_Market_Analysis_Excel.xlsx – Excel analysis
- Stock_Market_Analysis_PowerBI.pbix – Power BI dashboard
- Stock_Market_Analysis_Tableau_Dashboard.twbx – Tableau dashboard
- Dashboard screenshots

## Key Insights
- Analyzed stock price trends
- Compared opening and closing prices
- Tracked high and low prices
- Created interactive dashboards
- Used charts and filters for better analysis
