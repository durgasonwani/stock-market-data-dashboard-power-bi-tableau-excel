# 📈 Stock Market Data Analysis Dashboard

A complete **Stock Market Data Analysis Dashboard** created using **Power BI, Tableau, and Microsoft Excel**. This project analyzes stock market performance and presents meaningful insights through interactive dashboards and visual reports.

---

## 🌟 Project Overview

The purpose of this project is to analyze stock market data and understand price movements, trends, and overall stock performance.

Using this dashboard, users can easily track important stock values such as opening price, closing price, highest price, lowest price, and market trends.

This project demonstrates data analysis, dashboard development, data visualization, and reporting skills.

## 🧹 Data Cleaning and Preparation

Before creating the dashboards, the stock market dataset was cleaned and prepared for analysis.

* Checked and removed duplicate records
* Handled missing or blank values
* Formatted date columns correctly
* Converted price columns into numeric format
* Created calculated columns for better analysis
* Organized the data for dashboard reporting

## ▶️ How to Use This Project

1. Download or clone this repository.
2. Open `Stock_Data.xlsx` to view the raw dataset.
3. Open `Stock_Market_Analysis_Excel.xlsx` to view the Excel dashboard.
4. Open `Stock_Market_Analysis_PowerBI.pbix` in Power BI Desktop.
5. Open `Stock_Market_Analysis_Tableau_Dashboard.twbx` in Tableau Desktop.
6. Use filters and slicers to explore stock market trends and performance.
